📊 日志分析 Dashboard - 嵌入测试

📋 整个 Dashboard 嵌入信息

✅ 当前使用的是整个 Dashboard 嵌入方式

Dashboard UID: log-analysis

完整 URL:

https://prv.grafana.biya.io/d/log-analysis/log-analysis?orgId=1&from=now-24h&to=now&refresh=10s&kiosk=tv&theme=light

URL 参数说明:

  • d/log-analysis/log-analysis - 完整 Dashboard 路径（使用 d 而不是 d-solo）
  • orgId=1 - 组织 ID（默认 1）
  • from=now-24h&to=now - 初始时间范围（最新24小时）
  • refresh=10s - 自动刷新间隔（10秒）
  • kiosk=tv - 电视模式，隐藏顶部导航栏和工具栏（推荐用于嵌入）
  • theme=light - 浅色主题模式（light/dark）

💡 提示：Dashboard 顶部提供了时间范围选择器，可以动态切换查询时段：最新1小时、最新6小时、最新24小时、最新7天。选择后所有统计面板会自动更新。

📝 嵌入方式对比:

方式 URL 路径 说明
整个 Dashboard d/uid/title 显示完整 Dashboard，包含所有面板
单个面板 d-solo/uid/title 只显示单个面板，性能更好
